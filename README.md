# Installation

## BRAT Plugin (Recommended)

The most convenient way to install and manage updates for this theme is through the use of the [BRAT Obsidian plugin](https://github.com/TfTHacker/obsidian42-brat).

BRAT stands for "Beta Reviewers Auto-update Tool". While its main purpose is to help distribute beta versions of plugins and themes, it also works extremely well for automatically distributing updates for a stale theme.

1. Locate and install the BRAT plugin through the Community Plugins interface in Obsidian (`Settings -> Community plugins -> "Community plugins" section -> Browse`).
2. Enable the plugin.
3. Open the BRAT settings (`Settings -> "Community plugins" section -> BRAT`).
4. Scroll to the "Beta themes list section and click "Add beta theme".
5. Paste the link to this repository: https://github.com/samwbriggs/obsidian
6. Click "Add theme". The theme should be installed and applied automatically.

## Manual

If you prefer installing the theme manually, please reference the official Obsidian Docs: https://docs.obsidian.md/Themes/App+themes/Build+a+theme.
